# aula1-fundamentos

## O que é este projeto

Campo de treino da Aula 1 (Fundamentos) da Especialização em IA da PDA.
Projeto Node pequeno com funções utilitárias em `src/` e testes em `tests/`.

## Stack

- Node.js 18+
- Módulos ESM (`"type": "module"`)
- Runner de testes nativo do Node.js (`node:test`)

## Comandos

- Instalar dependências: `npm install`
- Executar testes: `npm test`
- Executar testes em modo watch: `npm run test:watch`

## Regras

- Sempre execute `npm test` antes de considerar uma tarefa concluída.
- Não altere arquivos em `tests/` sem solicitação explícita.
- Antes de editar, analise os arquivos relevantes e explique a abordagem.
- Faça apenas alterações necessárias para a tarefa.
- Depois da implementação, revise o diff e os resultados dos testes.

## Como eu quero trabalhar com você

- Antes de editar, explique em 1–2 frases o que vai mudar e por quê.
- Priorize mudanças pequenas e fáceis de revisar. Uma tarefa por vez.
- Se não tiver certeza sobre uma API ou lib, consulte a documentação (MCP Context7) em vez de chutar.
- Informe qualquer comportamento inesperado ou alteração fora do escopo.
